# Contributing to Rudi Agent

Greetings, Director. We are delighted that you are considering contributing to the development of Rudi Agent. To maintain the sophistication and reliability of these protocols, we request that you follow these guidelines.

## Our Philosophy
Rudi Agent is built on three core pillars:
1. **Uncompromising Privacy**: No external telemetry or cloud dependencies.
2. **Proactive Autonomy**: The agent should solve objectives, not just answer prompts.
3. **Refined Interface**: Every UI element and response must feel premium and intentional.

## How to Contribute

### Reporting Protocols
If you discover a breach in logic or a bug in the native bridge:
1. Open an Issue with the prefix `[PROTOCOL-FAIL]`.
2. Provide a detailed analysis of the expected vs. actual behavior.
3. Include relevant logic logs.

### Feature Suggestions
Propose refinements via the `[ENHANCEMENT]` prefix. We prioritize features that improve autonomy, vision analysis, or local performance.

### Logic Improvements (Pull Requests)
1. Fork the protocols.
2. Create your branch: `feature/new-protocol`.
3. Ensure all code passes the `npm run lint` audit.
4. Maintain the professional, sophisticated tone of the codebase in your commentary.

## Code of Conduct
Maintain a professional and helpful demeanor. Rudeness is not part of the Rudi Agent protocol.
